[1;33mKey Vulnerability:[0m
The CloudFormation stack has an administrative service role, and the user
can create and execute ChangeSets on the stack. This allows creating any
resource the service role has permissions for, including IAM roles with
trust policies that grant access back to the attacker.

[1;33mDifference from UpdateStack:[0m
Unlike UpdateStack which requires the full permission, CreateChangeSet and
ExecuteChangeSet allow more granular control. Many organizations grant these
permissions separately, thinking it provides better oversight. However, both
permissions together allow the same privilege escalation as UpdateStack.
